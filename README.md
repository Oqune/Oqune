### 🛡️ Core Focus

- 🔐 **Post-Quantum Cryptography (PQC):** Implementing lattice-based primitives (**ML-KEM-768**, **ML-DSA-65**) for quantum-resistant forward secrecy and identity authentication.
- ⚡ **High-Performance Networking:** Low-latency protocols via **WebTransport / QUIC**, custom binary frame serialization, and zero-trust transport layers.
- 🦀 **Modern Systems & Mobile:** High-reliability backend services in **Rust** and reactive, hardened Android clients in **Kotlin (Jetpack Compose)**.
